# OS Version
Show kernel version.  
```shell
uname -r
```

Show distribution version.  
```shell
cat /etc/os-release
```

# CPU
Shows CPU model, cores, threads, architecture.  
```shell
lscpu
```

# Shared Memory
Show shared memory size.
```shell
df -h /dev/shm
```

# Users and Groups
Show the user's UID, GID and groups.
```shell
id
```

Show the user's groups.
```shell
groups
```
